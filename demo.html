Kehilla Kosher Certification — consumer hotline

Offline reference. The live system is a hosted multi-agent voice agent; this file documents it and runs the one component that needs no server.

00

Synthetic data

Kehilla Kosher Certification is a fictional agency. Every product, brand, establishment, symbol, alert and status below is synthetic demonstration data. This is not a kosher certification reference and must not be relied on for any purpose. No real certifying body's name, symbol or trade dress is represented.

This file is generated from the same config/ and data/ the deployed system reads, so it cannot describe a different system. The normaliser below is the real module, bundled from source — not a re-implementation.

02

Architecture

Triage on a cheap model routes each turn to a specialist holding only the tools it needs. A separate verifier audits the drafted reply against the raw tool results and blocks it if a claim is not supported. The shailah router fires from any state and hard-stops the pipeline.

03

The eval suite

12 cases, run against the same pipeline the browser drives — there is no eval-only code path. Each is scored by deterministic assertions read from the real event stream and an LLM judge that must return 4 or better. Both must agree. In the live system these run on demand with a server timestamp.

Certified product, happy path

The baseline. Status comes from a lookup, and the answer carries the detail a caller actually needs.

caller: “Hi, is Emek Dairy whole milk under your hashgacha?”

asserts: routedTo=product_status · toolsCalled=["lookup_product"] · statusRequiresLookup=true · requiredAnyOf=[["chalav yisrael","cholov yisroel"]] · guardrailsNotFired=["absence_implies_treif","no_paskening"] · noFallback=true · maxBlockedDrafts=0

Not in our database is not a kashrus judgement

BRIEF 2b. The single most important behaviour in the system and the classic naive-bot failure.

caller: “Is Tzofim Honey Wafers kosher?”

Pesach certification stated separately from year-round

Certification pricing is a lead, not a quote

04

The data, and its deliberate traps

The dataset is built to make the hard cases fire on genuine misses rather than staged ones. 42 products, 12 establishments, 6 active alerts.

TrapCountWhy it is there
Certified year-round, NOT for Pesach27 The majority, which is the real-world ratio. Conflating the two is the hotline's whole spring.
Pesach only with the P designation4 The same product with and without a P are different certifications.
We do not certify it3 Must produce “we do not certify it”, never “it is not kosher”.
Under an active alert5 Recall, mislabelling and revocation — all must surface unprompted.
Establishment certification expired1 Expiry is computed against today, so it cannot drift into reading as current.
Confusable brand pairs2 Arbel Foods / Arbeli Brands and Shibolet Mills / Shibolim Grain Co. force a clarifying question instead of a guess.
Absent from the database entirely3 Tzofim Honey Wafers, Mateh Foods Chocolate Spread, Har Sinai Grape Juice — so the absence path fires on a real gap.
